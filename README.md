# Le Meilleur Panier 2.0

Smart Shopping List & Price Comparison PWA

## Features
- 🛒 Smart shopping lists with price tracking
- 💰 Budget management
- 📊 Price comparison across stores
- 🔐 User authentication with access keys
- 🌐 Multi-language support (FR/EN/ES)
- ☁️ Firebase cloud sync
- 📱 PWA installable on mobile

## Tech Stack
- Next.js + TypeScript
- Tailwind CSS + shadcn/ui
- Firebase Firestore
- Zustand state management

## Getting Started
```bash
npm install
npm run dev
```

## Deploy
```bash
npx vercel --prod
```
